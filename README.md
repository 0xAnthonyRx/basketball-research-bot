# Basketball Research Bot

Automated system that randomly samples basketball research from 70 top journals and emails plain-language summaries.

**Features:**
- Samples 5-15 articles from each of 70 reputable journals
- Generates plain-language summaries using AI
- Sends beautiful HTML email digest
- Runs automatically every Tuesday & Thursday at 11 AM EST

**Powered by:**
- PubMed, Europe PMC, CrossRef APIs
- Groq AI (Llama 3.1)
- Gmail API
- GitHub Actions
